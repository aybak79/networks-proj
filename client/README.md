# Link Frontend

The `client` directory contains the React/Vite frontend for the Link chat application.

For the complete setup guide, see the repository [README](../README.md).

## Local setup

```bash
npm install
npm run dev
```

The development server normally runs at `http://localhost:5173`.

## Validation

```bash
npm run lint
npm run build
```

The application currently uses local mock data, so the frontend can be developed and previewed without starting the backend.
